# Multi-Agent Opinion Dynamics with Stubborn Truth Agents and Random Edge Failures

**Graduate course research project** · AAE 59000 — Multi-Agent Autonomy & Control · Purdue University · Spring 2026

This repository contains notebooks developed in **Google Colab**, recorded experimental plots, and a course report investigating how **stubborn truth agents** affect opinion dynamics on networks with intermittent communication links. The project explores convergence behavior as the number of agents, number of stubborn agents, edge-failure probability, and graph density change.

> **Project status:** This is a graduate *course project*, not a peer-reviewed publication. The simulation notebooks were run interactively in Google Colab. Results from separate experimental runs were manually recorded in tables and used to generate the final comparison plots; this was not an automated experiment-to-plot pipeline. See [Reproducibility notes](#reproducibility-notes) before interpreting the figures.

## Research questions

- How do stubborn agents holding a fixed reference opinion influence the evolution of other agents' opinions?
- How does the number of stubborn agents relate to observed convergence time?
- How do randomly unavailable communication edges and the network's connectivity affect convergence in the tested settings?

## Model used in the notebooks

The simulation notebooks generate an Erdős–Rényi random graph with `N` agents and connection probability `p`. Each agent has an opinion `x_i(t)` initially sampled between 0 and 1. Selected **stubborn agents** are fixed at the reference opinion **1.0**.

At every time step, each *non-stubborn* agent updates its opinion to the arithmetic mean of its **currently available neighbors' previous opinions**:

```text
x_i(t+1) = mean( x_j(t) for j in active_neighbors(i, t) )
```

If no neighbors are available, the agent retains its previous opinion; stubborn agents remain at `1.0`. In the edge-failure notebook, each edge of the base graph is independently removed for that time step with probability `p_fail`; the base graph is restored before sampling failures at the following time step.

**Important interpretation:** The implementation averages *neighbor* opinions (not necessarily the agent's own opinion), and its stopping rule checks whether the state changes very little over a window of steps. A small state change is **not automatically proof of convergence to the truth value**. Convergence can depend on network connectivity and update-rule assumptions; the results here describe simulated configurations, not a theorem about all networks.

## Experimental workflow and recorded figures

This project was developed and executed in **Google Colab**. I ran simulations while varying parameters, recorded the resulting convergence times and other summary values **manually**, and entered those measurements into tables in `Convergence Simulation Experiments.ipynb`. That notebook reads the tables and generates comparison plots. I downloaded the figures and incorporated selected results into my course report, which I wrote in **Overleaf**.

**The plotted tables are a record of prior runs, not automatically generated outputs from the simulation notebooks.** Re-running a simulation may produce different values because graph initialization, agent states, and communication failures can be stochastic. The simulation notebooks and plotting notebooks can therefore be explored independently.

The recorded-data notebook plots six comparisons:

1. Number of agents versus observed convergence time **without** stubborn agents.
2. Number of agents versus observed convergence time **with one** stubborn agent.
3. Number of stubborn agents versus convergence time in a **20-agent** setting.
4. Number of stubborn agents versus convergence time in a **100-agent** setting.
5. Edge-failure probability versus convergence time.
6. Graph density versus convergence time.

## Run in Google Colab (recommended)

**You do not need to install Jupyter or Python on your computer.** The original work was done in [Google Colab](https://colab.research.google.com/), and you can explore the notebooks in a browser:

1. Open [Google Colab](https://colab.research.google.com/) and sign in.
2. Choose **File, Open notebook, GitHub**, then enter this repository URL: `https://github.com/AngadQ/multi-agent-opinion-dynamics`.
3. Choose a notebook from the `notebooks/` folder. Alternatively, download a `.ipynb` file from GitHub and choose **File, Upload notebook** in Colab.
4. Select **Runtime, Run all** (or execute cells individually). For the two main simulation notebooks, try changing `N`, `p`, `num_stubborn`, or `p_fail` and observe the resulting behavior.
5. For the recorded-data plotting notebook, edit the existing data tables to regenerate the comparison figures. **Those tables will not update automatically** when you run a different simulation.

The Python packages used are listed in [`requirements.txt`](requirements.txt). Colab often has several preinstalled; if an import is unavailable, install the missing dependency in a notebook cell, for example `!pip install networkx`. Colab package versions can change, so the results have not been validated against a fixed Colab runtime.

**Note:** The final sample plotting cell in `Convergence Simulation Experiments.ipynb` references undefined variables and should be skipped until corrected. Consequently, using **Run all** on that notebook as currently committed may report an error; the earlier recorded-data plots can still be run separately.
